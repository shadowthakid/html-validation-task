HTML VALIDATION PROJECT

Files
- broken.html: intentionally malformed original. Keep unchanged.
- fixed.html: corrected document.
- images/campus-life.svg: local image used by fixed.html.
- problem-fix-table.csv: problem, location, fix and reason table.

VALIDATION STEPS
1. Open https://validator.w3.org/nu/
2. Choose the File Upload option.
3. Upload broken.html and run the checker.
4. Capture a screenshot showing the checker results and the filename or document context.
5. Upload fixed.html and run the checker again.
6. Confirm the checker reports no errors. Review any warnings too.
7. Capture a screenshot showing the successful final result.
8. Keep both screenshots with this project. Suggested names:
   - validation-broken.png
   - validation-fixed.png

IMPORTANT
The screenshots are evidence and must be captured from the real W3C Nu HTML Checker.
Do not edit broken.html after capturing the initial validation evidence.
For a public project link, upload the project to a public GitHub repository. If you want a live website, enable GitHub Pages in the repository settings. The project files can be inspected in the repository even without Pages.

Suggested repository name: html-validation-competency-gate
